# Cars Dealership – Full-Stack Development Capstone Project

**Repository Name:** cars-dealership-capstone

**Project Name:** Cars Dealership – Full-Stack Development Capstone Project

## Project Description

A full-stack web application for a car dealership retailer in the United States. The application allows users to explore dealership locations, view dealer information, register and log in, and submit reviews.

## Technologies

- Frontend: HTML, CSS, JavaScript, React
- Backend: Django and REST APIs
- Database: SQLite
- Version Control: Git and GitHub
- CI/CD: GitHub Actions
- Deployment: Docker and cloud deployment
